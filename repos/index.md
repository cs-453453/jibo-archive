## Contributing Repositories

Know of an awesome Jibo-related repository? Help us build this collection!

1. Fork the [archive repository](https://github.com/cs-453453/jibo-archive)
2. Update this page with the repository details
3. Include the repo name, a brief description, and link
4. Submit a pull request

We're looking for:
- **Code projects** - Jibo SDKs, libraries, and tools
- **Documentation** - Guides and tutorials
- **Archives** - Historical documentation and resources
- **Community projects** - Fan-made content and experiments
