## Contributing Photos

We'd love to expand this gallery! If you have Jibo photos you'd like to share:

1. Fork the [repository](https://github.com/cs-453453/jibo-archive)
2. Add your photo to the `/photos` directory
3. Update this index with the photo details
4. Submit a pull request

Please include:
- A descriptive filename
- Original source attribution
- Any relevant context or stories
